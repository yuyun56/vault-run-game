Vault Run is a 2D top-down heist game: slip a thief across three guarded floors — a bank lobby, a gallery of kings and a crown vault — staying out of patrol guards' vision cones and the sweep of security cameras, hiding behind pillars and display cases, tossing coins to pull guards off their routes, cracking the vault and reaching the exit before the alarm meter fills. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
